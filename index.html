Share access

Generates a link with this connection already filled in, so someone new can open it and land straight in the app instead of typing owner/repo/path/token by hand. Opening the link fills the connection in automatically; on a browser that isn't connected to anything yet, it connects right away with no extra click.

The link carries the token in plain text — treat it like a password. Prefer minting a separate token per person (Change GitHub connection) so any one link can be revoked later without breaking everyone else's.

Ask AI (Claude)

Powers the "Ask AI" button in the bottom-right corner. Get a key from console.anthropic.com → API Keys. The key is stored only in this browser and is never synced to GitHub or shared — each device needs its own. Usage is billed to your Anthropic account (a typical question costs well under a cent).

For privacy: your question and an inventory snapshot are sent to Anthropic's API when you ask. Anthropic does not train on API data.

Estimated cost

Estimated from token counts returned by the API, using list prices for the model used. Tracked only in this browser (not synced). Reset counters

Export to CSV

Backup and reset

The shared copy of this data lives in your private GitHub repo (see GitHub Sync above). This browser also keeps a local backup copy in case GitHub is briefly unreachable — export a JSON backup periodically for extra safety.

Bulk cleanup

For most cleanup, go to the Inventory tab and use the checkboxes on the left of each row instead — select just the filaments you mean to change (like high-traffic loose spools you don't track closely) and use the bulk actions that appear. That keeps rare or intentionally-tracked items untouched.

This isn't selective — it zeroes every filament's loose count at once, common or rare. Use it only if loose tracking has gotten messy across the board and you want a clean slate. Like everything else here, it's undoable for 20 seconds right after.

Import spare parts from CSV

Paste CSV text below, or pick a .csv file. Expected columns, in order:
Barcode, Qty, Item Name, MPN, Category, Compatible Models, Description, Source/Notes
A header row is detected and skipped automatically. Rows whose barcode (or name + MPN) match an existing part update that part's quantity and fill in blanks; everything else is added as new.
